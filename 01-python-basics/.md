# Python Basics - Day 2 Learning at LinuxWorld

## Introduction to Python
Python is a high-level, interpreted programming language known for its simple syntax and wide range of applications in automation, web development, data science, cloud computing, and artificial intelligence.

## Why Python is Important
- Easy to learn and read
- Large collection of libraries
- Used in DevOps automation
- Supports cloud scripting
- Popular in AI and Machine Learning

## Topics Covered
- Indentation
- Variables
- Keywords
- Identifiers
- Operators
- Type Conversion
- Built-in Functions
- Primitive Data Types
- If-Else Statements

## Built-in Functions
- `input()` – Takes user input
- `type()` – Returns the data type
- `bin()` – Converts a number to binary

## Primitive Data Types
- int
- float
- str
- bool
