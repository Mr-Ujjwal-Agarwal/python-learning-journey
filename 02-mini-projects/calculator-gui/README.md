# GUI Calculator using Python Tkinter

## Description
A simple GUI-based calculator built using Python and Tkinter.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Backspace
- Decimal support

## Technologies Used
- Python
- Tkinter

This project helped me understand:
- GUI development
- Functions
- Event handling
- Arithmetic operations
- Tkinter widgets
