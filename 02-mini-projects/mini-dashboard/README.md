# Mini Desktop Dashboard using Python Tkinter

## Description
A multi-functional desktop dashboard application developed using Python Tkinter.

## Modules Included
- Scientific Calculator
- Unit Converter
- Secret Diary
- Guessing Game
- Digital Clock
- Password Generator
- To-Do List

## Technologies Used
- Python
- Tkinter
- Random
- Math
- File Handling

This project helped me understand:
- GUI application development
- Multi-window applications
- File handling
- Event-driven programming
- Python libraries integration
