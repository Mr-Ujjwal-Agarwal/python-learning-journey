# Retro Game using Python Turtle

## Description
A simple retro-style game developed using Python Turtle graphics.

## Features
- Player movement
- Falling object mechanics
- Score tracking
- Keyboard controls

## Technologies Used
- Python
- Turtle Graphics
- Random Module

## Learning Outcome
This project improved my understanding of:
- Game logic
- Loops
- Event handling
- Collision detection
- Real-time updates
